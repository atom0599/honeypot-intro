# Honeypot-Based Cyberattack Analysis System — 소개 페이지

T-Pot 허니팟 + LightGBM + Claude API 기반 사이버 공격 분석 시스템을 소개하는 Next.js 랜딩 페이지입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## Vercel 배포

1. 이 폴더를 GitHub 레포에 push 합니다.
2. https://vercel.com 에서 GitHub 계정으로 로그인 후 "Add New Project"로 해당 레포를 선택합니다.
3. Framework Preset은 Next.js로 자동 감지되며, 별도 설정 없이 Deploy를 누르면 됩니다.
4. main 브랜치에 push할 때마다 자동으로 재배포됩니다.
